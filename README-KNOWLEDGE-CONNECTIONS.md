# Patch 1 — Knowledge Connections
Áp dụng sau patch Storyteller/PWA hiện tại.

- Thêm data quan hệ tri thức cho Hà Nội, Huế, TP.HCM.
- Khi Storyteller kết thúc sẽ hiện `KẾT NỐI TRI THỨC → Khám phá tiếp`.
- Mỗi điểm có 3 node liên quan.
- Click node mở modal giải thích quan hệ Điểm đến → Node.
- Hỗ trợ VI / EN / ZH và responsive.
- Đây là MVP knowledge graph: node liên quan chưa phải trang độc lập.
